01

A・森好食

北門 → 十字路。經樟腦寮、第三觀景台、奮起湖與多林緩行，安排福森號餐盒。 留意車窗外的山景與檜木車廂細節，停靠與下車拍照依領隊安排。

02

C・好森音

阿里山 → 奮起湖。經二萬坪與多林緩行，欣賞山林風景與森林音樂體驗。 隨身攜帶乘車資訊與飲用水，移動時留意列車階梯與行李。

03

姊妹潭與森林漫步

第一天 14:30–16:00 安排森林遊樂區漫步，依領隊動線走訪姊妹潭與周邊景點。山林步道請穿防滑鞋，拍照時留意隊伍與路面。

YUYUPAS 優遊吧斯
