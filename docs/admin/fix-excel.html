Excel 讀取修正

這次只需更新 Apps Script。修正讀取 .xlsx 時交給 Google 解壓縮的檔案類型，原始 Excel 不需要改名或轉檔。

更新 Apps Script

開啟原本的 Apps Script ↗
  1. 按上方複製按鈕，在 Code.gs 全選後貼上，再儲存。
  2. 點「部署 → 管理部署作業」，選原本的網頁應用程式。
  3. 點編輯圖示，版本選「新版本」，再按部署。沿用原本 /exec 網址。
  4. 完成後重新傳送同一份 Excel，核對匯入預覽。按確認前不會寫入名單。

Cloudflare 這次不需要更新。原本的 API_SECRET、名單與綁定會沿用。
