旅行社 Excel 讀取修正

這次只需更新 Apps Script。Cloudflare 已完成車次功能的部署。

1. 複製完整程式

支援不同午餐區各自從第 1 桌編號；同一分頁左側放車次、右側放桌次，也可一起辨識。備註與接駁車名單會略過。

2. 儲存並更新原部署

開啟原本的 Apps Script ↗
  1. 將 Code.gs 全選，貼上完整程式並儲存。
  2. 點「部署 → 管理部署作業」，選原本的網頁應用程式。
  3. 點編輯圖示，版本選「新版本」，再按「部署」。沿用原本的 /exec 網址。

API_SECRET 等指令碼屬性沿用現有設定。

開啟部署版本檢查 ↗

看到 build 為 agency-layout-20261113，代表這次修正已上線。

3. 在 LINE 重傳原本 Excel

先核對名單，再核對所選行程的桌次，最後核對車次。每一步都先預覽，按「確認匯入」後才會寫入。

桌次仍按行程分別確認：福森號第1梯次、第2梯次、台中南投。若要更新三個行程，請重傳同一本，分別選擇行程，不用拆檔。

已存在的名單會比對更新。取消後面的步驟，前面已確認的資料仍會保留。上傳 .xlsx 才能保留姓名綠字或綠底的素食標記。
