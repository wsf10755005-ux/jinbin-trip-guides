整份 Excel 一次匯入

這次只需更新 Apps Script。Cloudflare 已完成車次功能的部署。

1. 複製完整程式

整本 Excel 上傳一次，系統依報名表的方案與梯次，整理福森號第1梯次、第2梯次和台中南投。名單、桌次與車次一起預覽，按一次確認即可匯入。

2. 儲存並更新原部署

開啟原本的 Apps Script ↗
  1. 將 Code.gs 全選，貼上完整程式並儲存。
  2. 點「部署 → 管理部署作業」，選原本的網頁應用程式。
  3. 點編輯圖示，版本選「新版本」，再按「部署」。沿用原本的 /exec 網址。

API_SECRET 等指令碼屬性沿用現有設定。

開啟部署版本檢查 ↗

看到 build 為 workbook-all-20261113，代表一次匯入功能已上線。

3. 在 LINE 重傳原本 Excel

核對總覽中的新增／更新人數，以及三個行程各自的桌次、車次人數，再按一次「確認匯入」。不必選行程，也不用重傳三次。

有同名、未知姓名、未分梯次或重複安排時，會先列出問題，本次資料暫不寫入。請修正後重傳。

已存在的名單會比對更新。按取消時，本次資料都不會寫入。上傳 .xlsx 會保留綠字／綠底素食標記，也支援姓名後的「純素」「方便素」註記。
