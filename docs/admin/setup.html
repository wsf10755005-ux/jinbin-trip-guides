名單、桌次與車次更新

已更新過車次功能，只有原排版 Excel 的桌次或車次辨識失敗時，請改用旅行社 Excel 讀取修正，只需更新 Apps Script。

這次新增「車次」查詢，請依序更新 Apps Script 和 Cloudflare 各一次。原本的 Excel 讀取修正已包含在這一版。

同一本 Excel 可放員工名單、桌次和車次分頁，系統會依序讓管理員預覽與確認。已存在的人員會比對更新；不會因為重傳同一份檔案重複新增。

1. 更新 Apps Script

名單 Excel 的「參加方案」可填 A、B、A+B，另加「梯次」欄填 1 或 2；只參加台中南投時，梯次留空。也可在參加方案直接填「福森號第1梯次」「福森號第2梯次」或「台中南投」。

開啟原本的 Apps Script ↗
  1. 將 Code.gs 全選，貼上複製的程式，再儲存。
  2. 點「部署 → 管理部署作業」，選原本的網頁應用程式。
  3. 點編輯圖示，版本選「新版本」，再按部署。沿用原本 /exec 網址。

2. 更新 Cloudflare Worker

開啟 Cloudflare ↗
  1. 進入 employee-trip-line-bot，點「編輯程式碼」。
  2. 全選原程式，貼上複製的完整程式，再按「部署」。

開啟手機管理頁 →

同一本 Excel 的確認順序

  1. 先核對名單；確認後寫入人員資料。名單完全相同時，直接接續其他分頁。
  2. 接著選擇桌次所屬行程、核對桌號與素食，另按一次確認。
  3. 最後核對車次，確認後更新人員的乘車安排。

每一步分別寫入。取消後面的步驟，不會回復前面已確認的資料。查無姓名、重名、停用或不屬於該行程的人員會列出，請核對後再確認。

之後怎麼匯入桌次

  1. 在官方帳號一對一聊天室，直接傳旅行社的桌次 .xlsx 檔，不用先輸入「管理」。
  2. 第一列是桌號，例如 1-1、1-2；每欄下面放同桌姓名，左側人數序號會略過。
  3. 選擇福森號第1梯次、第2梯次或台中南投，核對人數、桌號、素食及未配對名單。
  4. 按「確認匯入」後，更新該行程整份桌次。其他行程的安排會保留。

姓名文字或姓名格底色為綠色，會記為「素食」。桌次檔請保留 .xlsx；CSV 不會保留顏色。

請核對預覽中的素食名單。如果綠色是由「條件格式」自動顯示，請先改成姓名格固定的綠字或綠底再傳送。

員工點「桌次」，即可看到自己的桌號、同桌名單與本人素食標記。整個行程固定同一桌。

兩梯次共用同一張桌次表時，目前請先選第1梯次匯入，再重傳同一本並選第2梯次；不需要拆檔。每次只更新所選行程，不從桌號猜梯次。尚未分梯次者請先補名單。

車次 Excel 格式

保留旅行社的橫向排版：上方標明「福森號梯次1」「福森號梯次2」，下一列放「1-1車」「1-2車」「2-1車」等車號，每欄下面列出搭車人員；左側人數序號和中間空白欄會略過。

支援合併的梯次表頭與括號人數。完整車號會保留，不會從車號猜梯次。名單需先匯入，眷屬以自己的完整姓名配對。

車次匯入後存於「乘車安排」；桌次存於「用餐安排」。同時參加兩個行程的人，兩邊安排各自保存。

新的下方選單有五個按鈕：行程、車次、桌次、房號、旅遊攻略。部署完成後會切換新版選單。

名單匯入先核對預覽，再按「確認匯入」。尚未分梯次的新福森號人員，LINE 會提示聯絡承辦人。眷屬欄填 1，員工編號、部門可留空，仍可輸入全名綁定。

原本 ADMIN_PASSWORD、API_SECRET 和 LINE 密鑰會沿用。福森號兩梯次依旅行社參考行程整理，車票與集合時間以承辦人最終通知為準。
