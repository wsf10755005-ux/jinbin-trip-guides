福森號兩梯次更新

新版分為福森號第1梯次（AC）、第2梯次（BD）與台中南投（R02），依個人名單提供行程圖片、攻略、桌次與集合提醒。

1. 更新 Apps Script

Excel 的「參加方案」填原本 A 或 B，另外新增「福森號組合」欄，填 AC（第1梯次）或 BD（第2梯次）。眷屬也用相同格式。

開啟原本的 Apps Script ↗
  1. 將 Code.gs 全選，貼上複製的程式，再儲存。
  2. 點「部署 → 管理部署作業」，選原本的網頁應用程式。
  3. 點編輯圖示，版本選「新版本」，再按部署。沿用原本 /exec 網址。

2. 更新 Cloudflare Worker

開啟 Cloudflare ↗
  1. 進入 employee-trip-line-bot，點「編輯程式碼」。
  2. 全選原程式，貼上複製的完整程式，再按「部署」。

開啟手機管理頁 →

名單匯入先核對預覽，再按「確認匯入」。福森號組合空白時，LINE 會提示聯絡旅遊承辦人。管理頁可選「福森號全體」或指定組合發送提醒。

原本 ADMIN_PASSWORD、API_SECRET 和 LINE 密鑰會沿用。福森號兩梯次依旅行社參考行程整理，車票與集合時間以承辦人最終通知為準。
