金賓員工旅遊

名單與桌次匯入更新

Excel 讀取修正：若收到無法開啟檔案的訊息，請先完成這次 Apps Script 更新；Cloudflare 不需重複部署。

參加方案可填中文行程名稱。A 方案是福森號，以梯次 1、2 區分；B 方案是台中南投。管理員可直接傳桌次 Excel，先選行程、核對預覽，再確認匯入。

1. 更新 Apps Script

名單 Excel 的「參加方案」可填 A、B、A+B，另加「梯次」欄填 1 或 2；只參加台中南投時，梯次留空。也可在參加方案直接填「福森號第1梯次」「福森號第2梯次」或「台中南投」。

開啟原本的 Apps Script ↗
  1. 將 Code.gs 全選，貼上複製的程式，再儲存。
  2. 點「部署 → 管理部署作業」，選原本的網頁應用程式。
  3. 點編輯圖示，版本選「新版本」，再按部署。沿用原本 /exec 網址。

2. 更新 Cloudflare Worker

開啟 Cloudflare ↗
  1. 進入 employee-trip-line-bot，點「編輯程式碼」。
  2. 全選原程式，貼上複製的完整程式，再按「部署」。

開啟手機管理頁 →

之後怎麼匯入桌次

  1. 在官方帳號一對一聊天室，直接傳旅行社的桌次 .xlsx 檔，不用先輸入「管理」。
  2. 第一列是桌號，例如 1-1、1-2；每欄下面放同桌姓名，左側人數序號會略過。
  3. 選擇福森號第1梯次、第2梯次或台中南投，核對人數、桌號、素食及未配對名單。
  4. 按「確認匯入」後，更新該行程整份桌次。其他行程的安排會保留。

姓名文字或姓名格底色為綠色，會記為「素食」。桌次檔請保留 .xlsx；CSV 不會保留顏色。

請核對預覽中的素食名單。如果綠色是由「條件格式」自動顯示，請先改成姓名格固定的綠字或綠底再傳送。

員工點「桌次」，即可看到自己的桌號、同桌名單與本人素食標記。整個行程固定同一桌。

名單匯入先核對預覽，再按「確認匯入」。尚未分梯次的新福森號人員，LINE 會提示聯絡承辦人。眷屬欄填 1，員工編號、部門可留空，仍可輸入全名綁定。

原本 ADMIN_PASSWORD、API_SECRET 和 LINE 密鑰會沿用。福森號兩梯次依旅行社參考行程整理，車票與集合時間以承辦人最終通知為準。
