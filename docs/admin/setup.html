首次使用設定

只需用電腦設定一次。完成後，就能用手機管理集合提醒。

1. 更新 Apps Script

此版包含手機管理功能及日期讀取修正。

開啟原本的 Apps Script ↗
  1. 將 Code.gs 全選，貼上複製的程式，再儲存。
  2. 點「部署 → 管理部署作業」，選原本的網頁應用程式。
  3. 點編輯圖示，版本選「新版本」，再按部署。沿用原本 /exec 網址。

2. 更新 Cloudflare Worker

開啟 Cloudflare ↗
  1. 進入 employee-trip-line-bot，點「編輯程式碼」。
  2. 全選原程式，貼上複製的完整程式，再按「部署」。

3. 設定管理密碼

  1. 在同一支 Worker 的「設定 → 變數與密鑰」新增一項。
  2. 類型選 Secret，名稱填 ADMIN_PASSWORD。
  3. 值填你自訂的管理密碼，至少 12 個字元，再儲存並部署。

管理密碼由你自行保管，不需要傳到聊天室。原本的其他變數與密鑰保留。

開啟手機管理頁 →

第一次設定完成後，回 LINE 點一次「行程」，確認原本的查詢功能正常。集合提醒仍由原本每分鐘排程處理。

手機使用：以 Safari 或 Chrome 開啟管理頁，登入後可從瀏覽器選單「加入主畫面」。
