金賓員工旅遊

系統更新

完成下列兩項更新後，管理員可直接在 LINE 傳送員工名單、房號 Excel 或 CSV。

1. 更新 Apps Script

此版會合併 A＋B、匯入可自行綁定的眷屬，並讀取 R02 的「第二天上午選擇」。先顯示預覽，確認後才寫入員工名單。

開啟原本的 Apps Script ↗
  1. 將 Code.gs 全選，貼上複製的程式，再儲存。
  2. 點「部署 → 管理部署作業」，選原本的網頁應用程式。
  3. 點編輯圖示，版本選「新版本」，再按部署。沿用原本 /exec 網址。

2. 更新 Cloudflare Worker

開啟 Cloudflare ↗
  1. 進入 employee-trip-line-bot，點「編輯程式碼」。
  2. 全選原程式，貼上複製的完整程式，再按「部署」。

3. 管理密碼

原本的 ADMIN_PASSWORD 與其他變數、密鑰全部保留，不需重設。

開啟手機管理頁 →

更新後先回 LINE 點一次「行程」，確認原本四個查詢功能正常。R02 會在行程圖片後顯示第二天上午安排。管理員傳送 Excel 後，未按「確認匯入」不會改資料。

手機使用：以 Safari 或 Chrome 開啟管理頁，登入後可從瀏覽器選單「加入主畫面」。
