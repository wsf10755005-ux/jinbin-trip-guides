② 開啟 Cloudflare
  1. 先按上方「複製更新程式」。
  2. 進入 Cloudflare → Workers & Pages → employee-trip-line-bot。
  3. 點 Edit code／編輯程式碼，全選原程式、貼上，再按 Deploy／部署。

手機若看不到編輯畫面，請在瀏覽器選單切換「電腦版網站」。

無法複製？展開手動選取

長按文字，選「全選」→「複製」。

本頁不會自動部署。部署完成後，回 LINE 點「行程」測試。
